# Heer Prajapati - Portfolio Website

> Official personal portfolio website of **Heer Prajapati** — MCA Scholar at Ganpat University, Web Developer, and Python Enthusiast.

## 🌟 Highlights
- **Framework**: Next.js 16 (App Router) + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism System
- **Icons**: Lucide Icons
- **Interactive Certificate Viewer**: 11+ Verified Certificates (Infosys Springboard, IBM SkillsBuild, Skill India) with live modal preview, direct PDF hyperlinking, and download features.
- **Projects**:
  - **E-Commerce Website** (Web-based grocery shopping concept with PHP & SQL)
  - **AI Mock Interview** (Intelligent interview-practice platform with Python & Supabase)
- **Education**: MCA (Pursuing, Ganpat University 2025-2027) | BCA (HNGU, CGPA 8.16)
